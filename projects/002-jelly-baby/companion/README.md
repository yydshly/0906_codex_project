# 青团 · 会回应的三维果冻伙伴

基于 Jelly-Baby `df52c92a8459286bb287f0849764929e73b4f8ce` 的研究扩展。上游来源：https://github.com/scottstts/Jelly-Baby 。此目录只保存修改/新增的运行源码，不复制完整上游项目。

## 已实现

- 大眼白、独立瞳孔与高光、头顶叶芽；收窄躯干并拉高站姿，调整镜头留出跳跃空间。
- 指针方向驱动瞳孔；非等间隔眨眼；好奇、开心、惊讶、困倦四种状态。
- 原库准确抓取成功后发送事件，抓取时惊讶，释放后开心；短触碰按命中点相对身体中心的高度区分摸头与戳肚子；长按/拖动后的释放进入恢复动作。12 秒无操作进入困倦。手动表情展示 5 秒后返回自然交互。
- “开心跳跃”和任务完成先蓄力再调用 Locomotion.jump；打招呼挥手、摸头歪头、戳肚子缩身、拉伸后晃动恢复。动作改变节点目标驱动力，不直接覆盖物理位置。
- 眼睛、嘴巴和眉毛的表情变形在身体表面的局部切平面内完成，基础附件仍随原库表皮绑定更新。没有用二维动画代替三维求解。
- 关闭 iframe 释放运行资源；主页面原版与伙伴互斥运行。减少动态效果偏好下禁用自动眨眼，显式用户物理操作仍有效。

## 原理与边界

`input.ts` 暴露真实抓取/释放事件；新增 `Companion` 将指针、闲置、按钮和抓取事件映射为状态；`Baby` 负责三维表情变形。物理求解器与网格拓扑保留；初始化时对内部节点做连续轮廓映射，重算静止四面体体积、总质量所需体积、两套表皮与法线，并验证所有四面体未翻转。Locomotion 增加平滑的歪头、低头、挥手、缩身与微呼吸目标，抓取时仍释放驱动力。

当前进行了保守轮廓重映射，没有重建拓扑或独立的小手脚。低头、侧倾和挥手为软体目标姿态近似，尚非骨骼关节动画。人格记忆、语音、养成、计时器和真实业务系统尚未实现；本页已有品牌事件联动演示。眼睛注视采用屏幕方向到局部表面的近似映射；极端拉伸、翻转和不同镜头下的效果仍需长期验证。材质和焦散保留实时近似，不用于光学标定。

## 构建与运行

准备固定提交的上游运行源码、素材和 package-lock.json，再执行：

```powershell
node projects/002-jelly-baby/companion/build.mjs <固定版本上游目录>
python -m http.server 8765 --directory docs --bind 127.0.0.1
```

构建脚本将必需源码复制至上游目录同级 `companion-build/`，覆盖本目录文件，执行 npm ci、TypeScript 检查与 Vite 构建。产物写入 `docs/demos/002-jelly-baby/companion/`。原始构建目录不被修改。使用固定版本、空的 companion-build 目录可进行完全干净的复现。

模型和环境文件通过相对路径共享 `../original/assets/` 下的原版资源；不能只部署 companion 子目录。需 WebGPU 和 localhost/HTTPS。主页面：`http://127.0.0.1:8765/demos/002-jelly-baby/#extensions`。

## 使用场景与后续方向

| 场景 | 当前可复用 | 后续开发 |
| --- | --- | --- |
| 品牌网页伙伴（本页已验证事件联动） | 欢迎挥手、等待陪伴、完成庆祝 | 接入真实业务流程、自有模型与装扮 |
| 专注陪伴 | 闲置和困倦状态、安静的视觉反馈 | 计时器、专注/休息逻辑、提醒节奏 |
| 养成宠物 | 互动与情绪表现 | 精力、心情、喂食与存档 |
| 解压玩具 | 原版揉捏、回弹和新增表情 | 触控手感、操作节奏与音效配合 |
| 物理课堂（已实现单场景） | 真实拉伸、回弹观察、解释与完成反馈 | 参数对照、更多教学任务与效果评估 |
| 软体闯关 | 原版行走、跳跃、抓取 | 障碍碰撞、形变目标、关卡与计分 |
| 语音助手（后期） | 三维表情表现层 | 对话与语音服务、聆听状态、口型同步 |

我们的价值在于沉淀状态控制、表情变形和交互事件三个模块，而不是每个场景各做一个互不相干的角色。品牌欢迎/等待/完成事件已在本页演示；首页索引导览与弹性课堂已实现，完整产品场景仍为计划。

## 第二版：品牌事件接口

宿主页面通过同源 iframe 的 `postMessage({type:'jelly-brand',event}, location.origin)` 驱动伙伴。白名单事件：`welcome`（欢迎）、`waiting`（等待）、`complete`（完成）、`selected`（选择后关注）。伙伴只接受同源父窗口消息，独立打开时可通过自身按钮体验相同动作。主页面会在伙伴尚未启动时提示先唤醒，不丢弃按钮动作后伪报成功。

新增 `verify.mjs`：构建后执行 `node --experimental-strip-types projects/002-jelly-baby/companion/verify.mjs <companion-build目录>`，使用真实模型和求解器验证全部静止四面体、七组姿态、跳跃及重置。短程数值测试不等于所有设备或极端操作的稳定性保证。
