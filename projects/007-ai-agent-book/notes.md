### 稳定结论

1. 上游是教材、参考实现和实验档案的组合，不是单一生产框架或一体化 Agent 应用。
2. 最小 Agent 是模型、上下文和工具；生产工程还需要 Harness 管理循环、权限、状态、预算、错误恢复和验证。
3. 知识、工具、多模态、多 Agent 和持续进化都建立在同一“动作—观察—再决策”循环上。
4. 仓库用 evidence / ledger / manifest 区分实现存在、实际执行和正式验收，并保留负结果。
5. 对本研究库最直接的价值是实验方法：固定版本、保存轨迹、设定验收、比较方案、记录边界。

### 待验证事项
