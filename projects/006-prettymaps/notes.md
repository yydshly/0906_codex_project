## 2026-09-07 · 第二阶段：真实场景、真实生成

用户需要实际使用场景与可查看效果，因此将默认页面从上游示例图库推进为西湖场景工作台。

### 实际运行

- 创建独立 Python 3.12.13 环境并成功安装固定提交 prettymaps 1.4.2。首次构建因 GBK 读取上游 README 失败，设置 PYTHONUTF8=1 后成功；依赖已冻结。
- 默认 Overpass 服务连续 429，停止该任务的重试；private.coffee 连接失败，VK Maps 标准状态轮询迟滞。依据 OSM 官方公共实例清单，使用 VK Maps interpreter 的有超时 GET 传输适配器获取原始 JSON。
- 适配器只更改 OSMnx 请求函数，未更改上游绘制逻辑或虚构地理形状。
- 成功执行 prettymaps.plot()，获取西湖东北岸真实数据并首次出图耗时 22.36 秒（不含失败尝试）。保存 913 个建筑要素、2506 条道路图边、7 个水域要素、19 个公园要素及边界。
- 复用保存的 GeoJSON，通过 prettymaps.draw.plot_gdf() 生成 7 张场景成品，每张约 1–3 秒。中文标题、比例尺、指北箭头、导览编号由本项目扩展绘图完成。
- 从快照选择六公园、三公园、一公园、涌金公园，保留 OSM relation 链接。编号位置为地物内部代表点，不是实际入口。
- 本地服务监听 127.0.0.1:8767，页面可调整标题、三种配色、四种图层并真实重新渲染。静态发布保留成品浏览与下载。

### 实际验证

- 目视检查首次原生出图、暖色海报与导览图：真实湖岸、街区、中文标题、四个编号、比例尺及署名均可见。
- 浏览器实际提交“我的西湖旅行 / 深夜金色”，后端生成 custom-edce6e077288199d.png/svg/json，耗时 2.69 秒；页面呈现新标题、夜色图及新的下载地址。
- 检查三个场景切换、道路单层选择、对应图层选中状态和导览地点原始链接。
- 390×844 手机视口无横向溢出；检查后恢复视口。
- 七张成品的 14 个 PNG/SVG 下载地址均返回 HTTP 200。

- live.js 语法校验通过；最终运行仓库 sync/check。
