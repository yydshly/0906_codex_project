## 已实现并保留的基线

- 自制风格化人物、房间、家具、杯子与小车，Three.js 在浏览器本地渲染；不调用大模型。
- 移动、拿取、放置、坐下、起身、上车、驾驶、下车八项体验；物品归属、座位及车辆占用、中断和重置规则。
- 程序化走跑、脚部接触、起步保护、摆臂、逐脚收步、减速及身体配合。
- 三种发型、两种脸型；上装、裤装和鞋型各两种，肤色、发色和搭配色；当前浏览器保存一套形象。
- V1 完整可运行留档及 22 个冻结文件散列检查；V2 工作内容与历史截图保留。
- 35 项自动化测试基线；真实浏览器在自定义搭配下完成 8 / 8。历史测试数量按对应轮次记录，不当作最新品质评分。

## 建议接手顺序

先完成 H01–H03 的设计包和实时头肩样板，外观认可后推进全身、衣物及交互。暂不继续扩大卡通衣橱的数量。性能预算从样板开始检查，不能到发布前才发现运行代价不可接受。

可沿用任务规则、物品归属、占用语义及回归场景；新引擎需要重新集成，现有 JavaScript 与动作参数不能视作自动兼容。新身体版本需重新验证衣物、鞋底高度、抓握与座位关系。

## 后续维护入口

在本项目执行 npm ci、npm test、npm run build；项目元数据变化时在根目录执行 npm run sync、npm run check。只编辑源文档与 src，不直接维护生成的 records 网页。每轮新增能力必须记录问题、修改、验证与未解决项。

历史文档中的“尚未提交”描述保留当时状态；当前交付范围以 Git 历史与本说明为准。V1 冻结目录不随新版构建覆盖。
