ABOUT THIS EXPERIMENT

从一个角色，到一种生活。

这是一个独立的原创子项目。人物造型、衣物、房间、小车、骨骼与动作均由本项目代码制作，验证运动、持物、座位和载具之间的连续行为。

人物采用程序化几何、骨骼蒙皮、程序化步态和手臂 IK，没有使用下载的人物、贴图或动作资产。Three.js 提供通用三维渲染工具。当前未接入大模型，也未实现自由捏脸、真实车辆动力学或完整养成玩法。

小车使用有限场地内的简化驾驶模型；拿取与坐姿只适配本房间的物品和座位。第一版重点是把动作与物品状态连起来，精细手指握持与上下车动作仍可继续打磨。
