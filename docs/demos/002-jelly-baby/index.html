A / PHYSICS

内部骨架，负责变形

CPU · WebAssembly / JavaScript
B / SURFACE

精细表皮，负责细节

72,234 个顶点通过权重跟随内部节点。身体、面部附件与选点共享变形后的几何。

CPU 更新 · GPU 渲染
C / LIGHT

光学代理，负责光影

20,176 个三角形用于较轻的光学计算。Worker 更新厚度与阴影，GPU 生成焦散。

Worker + GPU · 分工更新
深入一点：为什么它能像果冻？ ＋

弹性：neo-Hookean 型能量描述拉伸和体积变化，耦合 XPBD 迭代修正节点位置；阻尼让回弹逐渐消散。

运动：程序向节点施加姿态与步态驱动力，抓取时释放，松手后逐步恢复。它没有使用学习式运动控制。

材质：透射与厚度相关吸收产生通透观感。当前 GPU 焦散采用深度图、有限采样和模糊，属于实时近似。

源码核对：README 的 Worker 焦散与六步补算描述已滞后；本页依据 df52c92 的 GPU 焦散和最多十二步补算实现。

03.4 / WHAT IT MEANS FOR US

从会回应的伙伴，走向可复用的角色。

先验证角色的辨识度与互动反馈，
再接入页面场景、养成和更多动作。

交互价值把“柔软”变成用户可以直接操作的反馈，适合教学、角色与轻量游戏。

技术价值借鉴粗网格驱动精细外观，以及 CPU、Worker、GPU 分工的实现方法。

对我们的意义用小原型验证场景，再把有效的方案沉淀为可复用组件和研究实验。

投入前，需要知道的边界

运行：上游要求 WebGPU 与 HTTPS / localhost，没有 WebGL 后备。我们的二维原型不要求 WebGPU；嵌入的原版需要。

物理：没有自碰撞或撕裂；站立靠额外驱动力。展示效果不等于工程材料预测能力。

复用：当前快照未确认明确许可证，代码及纹理、模型的授权需核实；本地研究构建保留原版运行资源，未对外发布；来源与文件校验见研究记录。
